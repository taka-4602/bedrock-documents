# Bedrock（ベッドロック）— Discord メンバーブーストBot

**Bedrock** は OAuth2 認証を使った Discord メンバーブーストサービスです。

サーバーに「認証ボタン」を設置 → 押してくれた人を Bedrock が記録 → `/call` を実行すると、**Bedrock に登録されている人を一気にそのサーバーへ追加**します。

| リンク | URL |
|---|---|
| 導入ページ | <https://bedrock.aa-bot.com/installation> |
| 全体統計 | <https://bedrock.aa-bot.com/stats> |
| 認証済みBot | <https://verify.aabedrock.com> |
| サポート / 購入 | <https://discord.gg/Bjcas6u39u> |
| コミュニティ | <https://discord.gg/HvsQN786ut> |

## Botは2種類あります【おすすめは認証済みBot】

Bedrock には2種類のBotがあります。**機能（コマンド・クレジット・購入）はどちらも同じ**で、違いは「導入できる数」と「自動退出の有無」だけです。

| | **認証済みBot（おすすめ）** | 未認証ベッドロック（1〜6） |
|---|---|---|
| Discord 認証バッジ | ✓ あり | なし |
| 導入できるサーバー数 | **無制限** | 1台あたり上限あり（満員だと入れない） |
| 自動退出 | **なし（放置OK）** | 毎日 0:00 に非アクティブなサーバーから退出 |
| 台数 | 1台のみ（番号選択なし） | ベッドロック1〜6から選択 |
| Web | `verify.aabedrock.com` | `bedrock.aa-bot.com` |

### なぜ認証済みBotがおすすめなのか

- **満員で入れないことがない** — 未認証Botは1台あたりの導入数に上限があり、埋まると追加できません。認証済みBotはDiscordの審査を通過しているため上限がありません
- **抜けない** — 未認証Botは「毎日誰かが認証している状態」を維持しないと自動で退出します。認証済みBotは放置しても抜けません
- **選ぶだけで簡単** — 番号選び・枠の空き確認・「入らない」対応がすべて不要です

> ただし `/call` で呼べる人数は**登録者プールごとに違います**。認証済みBotと各ベッドロック番号は登録者・クレジットともに**完全に別枠**です。呼べる人数を重視する場合は `/datacheck` や `/stats` で比較してから決めてください。

## 使い方（導入〜/call まで）

### STEP 1. Botをサーバーに追加

<https://bedrock.aa-bot.com/installation> を開きます。

- **認証済みBot**: ページ上部の「認証済みBotが稼働中」バナーから追加（または `verify.aabedrock.com/installation`）
- **未認証ベッドロック**: 「Discordサーバーに追加」から番号（1〜6）を選択

権限は **管理者（Administrator）** のまま追加してください。権限を削ると `/call` が失敗し、サポート対象外になります。

### STEP 2. `/button_boost` でボタンを設置

認証ボタンを置きたいチャンネルで実行します。

```
/button_boost ロール:@認証済み
```

| 引数 | 必須 | 説明 |
|---|:--:|---|
| `ロール` | ✅ | 認証したメンバーに自動付与するロール |
| `タイトル` `説明` `ボタン文字` `画像` `アイコン画像` `ユーザーネーム` | | 埋め込みの見た目をカスタマイズ |

- **同じコマンドを再実行すれば設定を上書きできます**（認証済みデータは消えません）
- ⚠️ **Bot のロールを、付与するロールより上に配置してください**（サーバー設定 → ロール）。下にあると認証は成功してもロール付与だけ失敗します

### STEP 3. メンバーに認証してもらう

メンバーがボタンを押して認証すると、指定ロールが付与され、あなたのサーバーの**認証人数**が1増えます（同じ人の2回目はカウントされません）。

```
/usercount
```

で、認証人数・クレジット残高・次の無料 `/call` まであと何人かを確認できます。

### STEP 4. `/call` を実行

```
/call
```

Bedrock の登録者をあなたのサーバーへ順番に追加します。人数によっては数分〜数十分かかります。

### STEP 5. 維持する（未認証ベッドロックのみ）

未認証ベッドロックは毎日 **0:00（日本時間）** に、以下のサーバーから自動退出します。

- 認証者が **2人未満**
- **前日から認証人数が1人も増えていない**

放置すると必ず抜けるので、毎日誰かが認証している状態を保ってください。**認証済みBotは抜けないのでこの対応は不要です。**

## `/call` とクレジット

`/call` の実行には「無料枠」か「クレジット」が必要です。実行時に次の順で権利を探します。

```
① ハーフクレジットがある → 1つ消費して【ハーフ /call】（登録者の半分をランダムに追加）
② フルクレジットがある   → 1つ消費して【フル /call】（登録者全員を追加）
③ 無料枠の条件を満たす   → 無料で【フル /call】（進捗カウンタを0にリセット）
④ どれも無い             → 購入ボタンを表示
```

- ⚠️ **ハーフは必ずフルより先に消費されます。** フルを先に使いたいときはハーフを使い切ってから
- **クレジットで撃っても無料枠の進捗は消費しません。** 「20人貯まる直前にクレジットで1回→すぐ無料でもう1回」が可能

### 無料 `/call` の条件

1. **累計の認証人数** がしきい値以上（現在 20人）
2. **最後の `/call` からの認証人数** がしきい値以上（現在 20人）

> しきい値は運営が変更します。**常に `/usercount` の表示が正です。**
> [DisLounge](https://dislounge.net) 登録サーバーはしきい値 **-5人**・価格 **-10円**（ハーフ -5円）の優遇があります。

### クレジットの注意

- **Botごとに別枠** — ベッドロック1のクレジットでベッドロック2や認証済みBotの `/call` は撃てません
- **サーバー単位で保有** — 別サーバーへの移動は不可（個人アカウント残高は好きなサーバーに付与可）
- **認証人数はクレジットになりません** — 増えるのは無料枠の進捗だけです

## クレジットの購入（PayPay）

### 買える場所

| 場所 | 特徴 |
|---|---|
| **`/call` の購入ボタン**（自サーバー） | 権限が足りないときに出る。サーバーID入力不要で一番簡単 |
| **販売Botの購入ボタン**（サポートサーバー） | 対象Botを選んで購入。「全部買う」（未認証の全番号を-100円でまとめ買い）はこちらのみ |

### 価格

**そのBotの登録人数 ≒ 価格**（登録者1人あたり約1円が目安。登録人数から0〜50引いた額＋ランダム幅）。ハーフは約半額です。

### 手順

1. PayPayアプリ →「送る」→ **リンクを作成**（金額は表示価格ちょうど以上、パスワードは4桁数字か無し）
2. 購入ボタン → フォームに **サーバーID**（`/call` のボタンからは不要）と **送金リンク** を入力（PayPayのメッセージ丸ごと貼り付けOK）
3. 「Success!」が出れば付与完了

> 購入ボタンは **10分で期限切れ**。切れたら押し直してください。
> 「対応待ち（一時保留）」が出たら、PayPayアプリで送金を承認 → Discordの「確認」ボタンを押してください。

### よくある失敗

| メッセージ | 対処 |
|---|---|
| 送金リンクが見つかりません | `https://pay.paypay.ne.jp/...` を含めて貼り直す |
| 金額不足 | 価格ちょうど以上のリンクを作り直す |
| パスワードがついています / 数字4桁で | パスワード欄に4桁の数字を入力 |
| このボタンは期限切れです | `/call` またはボタンを押し直す |

### 「ベッドロックが入らない」とき（未認証のみ）

未認証ベッドロックは各 **100サーバー**まで。満員だとBotが入れません。サポートサーバーの「**ベッドロックが入らない**」ボタン（無料）で、直近に受け入れられなかったサーバーを退出させて枠を空けられます。**認証済みBotにこの問題はありません。**

### BAN解除（1500円）

ブラックリスト入りすると `/call` 実行時に「⚠️このサーバーはBANされています⚠️」と出ます。BAN解除ボタンから購入すれば、ユーザーBANとサーバーBANが同時に解除されます。

## コマンド一覧

全コマンドは **サーバー管理者専用**（`/help`・`/datacheck` を除く）で、DMでは使えません。認証済みBot・未認証どちらでも同じです。

| コマンド | 説明 |
|---|---|
| `/button_boost` | 認証ボタンを設置（ロール指定・見た目カスタマイズ可） |
| `/call` | 登録者をまとめて追加。`サーバー上限のユーザー情報を削除する:true` で上限到達ユーザーを登録リストから削除（⚠️全サーバーに影響） |
| `/usercount` | 認証人数・クレジット残高・無料枠までの残り人数 |
| `/dashboard` | このサーバーの統計ページURLを表示 |
| `/datacheck` | このBotの登録者総数を表示 |
| `/help` | ヘルプとサポートサーバーリンク |

ドメインはBotごとに分かれていますが、ページ構成は同じです（未認証: `bedrock.aa-bot.com` / 認証済み: `verify.aabedrock.com`）。

| ページ | 内容 |
|---|---|
| `/installation` | 導入ガイド |
| `/stats` | 全体統計 |
| `/s/<サーバーID>` | そのサーバーの公開統計（宣伝に貼れる） |
| `/dashboard/<サーバーID>` | 認証人数の推移グラフ |
| `/login` → `/me` | 個人ダッシュボード。自分のクレジット残高を好きなサーバーに付与できる（ログインは identify のみ・誰でも可・`guilds.join` は取りません） |

## ボタンを押して認証する人へ

1. ボタン → Discord の認可画面 →「認証」でロールが付き、あなたがそのBotの登録者リストに入ります
2. 渡す権限は `identify`（ID・名前・アイコンの読み取り）と **`guilds.join`（あなたをサーバーに参加させる）** の2つ
3. **`guilds.join` を許可すると、あなたが認証したサーバー以外にも、あとから自動で参加させられることがあります。** これが Bedrock の仕組みなので、納得できる場合だけ認証してください
4. メッセージの閲覧・送信、パスワード・メールアドレスの取得などは**できません**

## 困ったとき

### `/call` の結果メッセージの読み方

| 表示 | 意味 |
|---|---|
| ◯人を追加 | 実際に参加した人数 |
| ◯人は既に追加されていて | すでにこのサーバーのメンバー |
| ◯人の情報が失効済み | 認可取り消し等でトークン無効（自動削除されます） |
| ◯人はもうサーバーに参加できません | その人が100サーバー上限（Nitroは200）に到達 |
| ◯人はBANされています | あなたのサーバーでBAN済み |
| ◯人はアカウントが未認証です | メール/電話認証が未完了。サーバーの認証レベルを下げると入れる場合あり |
| ◯人の情報がリフレッシュされました | トークン自動更新（正常動作） |

### エラー・トラブル早見表

| 症状 | 原因・対処 |
|---|---|
| 「権限なし」 | 無料枠の条件未達かつクレジット無し。購入するか `/usercount` で残り人数を確認 |
| 「まずはボタンを配置してください」 | `/button_boost` が未実行 |
| 「すでに/callが実行されています」 | 前回の `/call` が実行中。終了を待つ |
| 「招待が停止されています」 | Discord側でそのサーバーの参加が停止中。回復を待って再実行 |
| ロールが付かない | Botのロールを付与するロールより**上**に移動 |
| 「Invalid Server ID」 | ボタンが古い。`/button_boost` で置き直し |
| **Botが勝手に抜けた（未認証）** | 毎日0:00の自動退出が仕様。入れ直して `/button_boost` をやり直せば認証データは残っています |
| **Botが追加できない（未認証）** | 80サーバー上限に到達。別番号・認証済みBot・「ベッドロックが入らない」ボタンを利用 |
| **認証済みBotがいない** | 自動退出はありません。キックされたかBot停止。入れ直すかサポートへ |
| Botが一切反応しない | BotがBAN/停止された可能性。別のBotで `/button_boost` を置き直し再認証が必要 |
